# 合作伙伴 Logo

把对应品牌的 logo 图片放到这个文件夹（`public/partners/`），文件名要和下面**完全一致**，
首页合作伙伴区会自动显示真实 logo；没放的会回退成首字徽标，不影响页面。

建议：透明背景 PNG 或 SVG，正方形或接近正方形，分辨率 ≥ 128px。
（若用 SVG，请把对应 data.ts 里的扩展名 .png 改成 .svg。）
